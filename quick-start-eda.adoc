= Schnellstart für Workload Factory für EDA
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Beginnen Sie mit Workload Factory for EDA, indem Sie Ihre Umgebung einrichten, Überwachungs-Dashboards aktivieren und die Latenzanalyse konfigurieren, um die FSx for ONTAP Performance für Ihre EDA-Workloads zu optimieren.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"] Melden Sie sich bei Workload Factory an.
[role="quick-margin-para"]
Du musst https://docs.netapp.com/us-en/workload-setup-admin/sign-up-saas.html["Richten Sie ein Konto bei Workload Factory ein."^] und melden Sie sich mit einem der folgenden Anmeldedaten an: https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["Konsolenerlebnisse"^]Die

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]Anmeldeinformationen und Berechtigungen hinzufügen
[role="quick-margin-para"]
Wählen Sie die Berechtigungsrichtlinien, die Ihren Anforderungen entsprechen.

[role="quick-margin-para"]
Wenn Sie keine Berechtigungen erteilen, können Sie mit Workload Factory for EDA beginnen, um teilweise fertiggestellte Codebeispiele zu kopieren.

[role="quick-margin-para"]
Wenn Sie Berechtigungen erteilen möchten, müssen Sie einem Konto manuell Anmeldeinformationen hinzufügen. Dazu gehört die Auswahl von Workload-Funktionen wie EDA und KI sowie die Erstellung der IAM-Richtlinien für die erforderlichen Berechtigungen.

[role="quick-margin-para"]
https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["Erfahren Sie, wie Sie Anmeldeinformationen und Berechtigungen hinzufügen."^]Die

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"] Richten Sie Ihre Umgebung so ein, dass sie die EDA-Anforderungen erfüllt.
[role="quick-margin-para"]
Sie benötigen ein bereitgestelltes und erkanntes FSx for ONTAP -Dateisystem, das mindestens ein Volume enthält, das als NFS-Freigabe konfiguriert wurde.

[role="quick-margin-para"]
link:requirements-eda.html["Erfahren Sie mehr über die EDA-Anforderungen."^]Die

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]Aktivieren Sie das Übersichts-Dashboard
[role="quick-margin-para"]
Aktivieren Sie das Übersichts-Dashboard, um den Zustand, die Kapazität und den Durchsatz Ihrer FSx for ONTAP Cluster zu überwachen. Bestätigen Sie die Zustimmungsanfrage, damit Workload Factory mit der Erfassung von CloudWatch Metriken beginnen kann.

[role="quick-margin-para"]
link:task-activate-overview-dashboard.html["Erfahren Sie, wie Sie das Übersichts-Dashboard aktivieren"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Fünf"]Konfigurieren Sie das Projects-Dashboard
[role="quick-margin-para"]
Konfigurieren Sie das Projects-Dashboard, um Systemzustand, Leistung und Speichernutzung zu überwachen und so Ihre EDA-Umgebung effektiv zu optimieren.

[role="quick-margin-para"]
link:task-configure-project-dashboard.html["Erfahren Sie, wie Sie das Projects-Dashboard konfigurieren."^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Sechs"]FSx für ONTAP Latenzanalyse konfigurieren
[role="quick-margin-para"]
Latenzschwellenwerte können eingerichtet werden, um Leistungsprobleme proaktiv zu identifizieren und zu beheben, bevor sie die Simulationslaufzeit beeinträchtigen. Warn- und kritische Benachrichtigungen lassen sich konfigurieren, E-Mail- oder SNS-Benachrichtigungen für den Empfang von Echtzeit-Benachrichtigungen einrichten, automatisierte Basisanalysen nutzen und optional KI-Analysen für komplexe Szenarien durch die Konfiguration einer Amazon Bedrock Modell-ARN aktivieren.

[role="quick-margin-para"]
link:task-configure-latency-monitoring.html["Erfahren Sie, wie Sie die Latenzüberwachung konfigurieren"^]. Sobald Ereignisse erkannt wurden, können Sie link:task-analyze-latency-trends.html["Latenztrends analysieren"^] das interaktive Diagramm verwenden.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["Sieben"] Integrieren mit anderen Diensten
[role="quick-margin-para"]
Integrieren Sie EDA mit anderen Diensten wie einem Serviceportal oder Perforce Helix Core mithilfe der Workload Factory REST API.

[role="quick-margin-para"]
link:integrate-perforce.html["Erfahren Sie, wie Sie EDA in Perforce integrieren."^]Die
