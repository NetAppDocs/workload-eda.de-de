= Aktivieren Sie das Übersichts-Dashboard in Workload Factory für EDA
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Das Übersichts-Dashboard kann aktiviert werden, um CloudWatch-Metriken für Ihre FSx for ONTAP Dateisysteme zu erfassen. Im Dashboard werden Clusterzustand, Kapazität und Durchsatz an einem Ort angezeigt.



[[before-you-begin]]
== Bevor Sie beginnen

Stellen Sie sicher, dass Sie die folgenden Anforderungen erfüllen, bevor Sie das Dashboard aktivieren.



[[aws-credentials-with-view-permissions]]
=== AWS-Anmeldeinformationen mit Ansichtsberechtigungen

Sie müssen in Workload Factory AWS-Anmeldeinformationen mit mindestens Leseberechtigungen (Anzeigeberechtigungen) für General Storage konfigurieren. _Basic_ Anmeldeinformationen werden nicht unterstützt, da sie nicht die erforderlichen Leseberechtigungen für CloudWatch-Metriken enthalten.

Wenn Sie keine Anmeldeinformationen mit Anzeigeberechtigungen konfiguriert haben, werden Sie beim Öffnen der Registerkarte „Übersicht“ auf die AWS-Anmeldeinformations-Einrichtungsseite weitergeleitet.

Wenn Sie noch keine AWS-Zugangsdaten konfiguriert haben, siehe link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["AWS-Anmeldeinformationen hinzufügen"^].



[[activate-the-dashboard]]
== Dashboard aktivieren

Nachdem Workload Factory die Anmeldeinformationen mit Ansichtsberechtigungen überprüft hat, wird das Dashboard aktiviert, um CloudWatch-Metriken für Ihre FSx for ONTAP Dateisysteme zu erfassen.


NOTE: Nachdem Sie Ihre Einwilligung erteilt haben, kann die Erfassung der Messwerte etwas Zeit in Anspruch nehmen. Das Dashboard benachrichtigt Sie, während die erste Erfassung läuft.

.Schritte
. Melden Sie sich mit einem der folgenden Dienste an: link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["Konsolenerlebnisse"^]Die
. Wählen Sie das Menü image:workloads-menu-icon.png["Das Hamburger-Menüsymbol"] und wählen Sie dann *EDA* aus.
. Wählen Sie die Registerkarte *Overview* aus.
. Falls keine Anmeldeinformationen mit Leseberechtigungen gefunden werden, wählen Sie *Anmeldeinformationen hinzufügen* und folgen Sie den Anweisungen, um AWS-Anmeldeinformationen mit Leseberechtigungen zu konfigurieren. Kehren Sie anschließend zur Registerkarte *Übersicht* zurück.
. Lesen Sie die Zustimmungsaufforderung, in der die CloudWatch-Metriken beschrieben werden, die für Ihre FSx for ONTAP Dateisysteme erfasst werden.
. Wählen Sie *Activate*, um das Dashboard zu aktivieren und mit der Metrikenerfassung zu beginnen.


.Ergebnis
Workload Factory beginnt mit der Erfassung von CloudWatch Metriken für alle FSx for ONTAP Dateisysteme, die mit Ihren AWS-Anmeldeinformationen verknüpft sind. Das Dashboard wird aktualisiert, sobald die Metriken verfügbar sind. Während der Datenerfassung erscheint eine Benachrichtigung.
